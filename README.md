# 🚀 HyprX

> A custom riced Hyprland setup built from scratch — messy, minimal, and mine.

HyprX is my personal Hyprland rice, crafted over weeks of breaking configs, fixing them, and learning Linux the hard way. This repo contains everything needed to replicate my setup — from packages to configs to shell theming.

## ✨ Features

- ⚡ Hyprland-based Wayland setup
- 🖥️ Clean and minimal UI
- 🎨 Custom Waybar, Rofi, Kitty configs
- 🔔 Notifications via swaync
- 🌙 Hyprsunset (night light) `
- 🧠 Zsh + Oh My Zsh + Powerlevel10k
- 🔗 Fully symlinked config structure
- 📦 Automated install script

---

## 🧠 What You’ll Learn

This setup touches a lot of Linux concepts:

- TTY / Shells
- Wayland vs Xorg
- Window Managers vs Desktop Environments
- Compositors
- GRUB / EFI / NVRAM
- systemd
- Dotfiles & Symlinks
- Package managers (pacman + yay)

## ⚙️ Installation

> ⚠️ **Do NOT run as root**

### 1. Clone the repo

```bash
git clone https://github.com/darkkphoenyx/HyprX
cd HyprX
```

Run

```bash
./install.sh
```
